<h1 align="center">Recoup Money</h1>

  <img src="https://img.shields.io/badge/Farming%20Simulator-25-2E6B4F" alt="Farming Simulator 25">

<p align="center">
  <b>Sell a silo, production, animal pen or any other building with goods still in it and get paid for what's inside instead of losing it.</b>
</p>

<p align="center">
  <a href="https://github.com/DTM-Mods/FS25_RecoupMoney/releases/latest"><img src="https://img.shields.io/badge/Download-latest%20release-D9A441?style=for-the-badge&logo=github&logoColor=143326&labelColor=E9C77A" alt="Download the latest release"></a>
</p>

<p align="center">
  <img src="https://raw.githubusercontent.com/DTM-Mods/.github/main/assets/features.jpg" alt="Features" width="100%">
</p>

- Every fill type is paid at the best price any selling point currently offers, the same prices shown in the price list.
- Goods that no selling point buys (chaff, manure, ...) are paid at their base price.
- Works for silos, silo extensions, production points, animal storages and feed, manure heaps, bunker silos and mod buildings that use a standard storage.
- The payout shows up as income and in a notification listing what was sold.

### Console command

| Command | What it does |
| --- | --- |
| `rmList [farmId]` | Every building holding goods and what selling it would pay |

<p align="center">
  <img src="https://raw.githubusercontent.com/DTM-Mods/.github/main/assets/installation.jpg" alt="Installation" width="100%">
</p>

Put `FS25_RecoupMoney.zip` in `Documents/My Games/FarmingSimulator2025/mods`. In multiplayer, install it on the server and on every player's game.
